## 2023-10-24 - [Command Injection via Git Refs]
**Vulnerability:** The `runGitDiff` function passes user-controlled git references directly to `child_process.spawn` without validating if they start with a hyphen (`-`). This could allow command injection or argument injection (e.g., passing `--upload-pack` or other unexpected arguments to git).
**Learning:** Even when using `spawn` with an array of arguments (which is generally safer than `exec`), we must ensure that dynamic arguments don't look like flags (starting with `-`), as the underlying binary might parse them as options, leading to unexpected behavior or remote code execution depending on the command.
**Prevention:** Always validate that dynamic inputs passed to child processes do not start with a hyphen (`-`), especially for commands like `git` or `gh`. If hyphens are legitimately needed, consider using the `--` separator to signify the end of options before passing dynamic arguments, or enforce strict whitelisting.
